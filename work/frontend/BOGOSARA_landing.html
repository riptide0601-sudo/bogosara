How it works

두 개의 입구,
하나의 이해

제품명을 알고 있다면 검색을, 눈앞의 제품을 바로 확인하고 싶다면 스캔을 선택합니다. 방식은 다르지만 도착지는 같습니다.

제품명 검색 · 제품 DB ↘ 전성분 확보 ↙ 전성분표 촬영 · OCR 인식
01 · MATCH

성분 DB 매칭

전성분을 성분 백과사전 DB와 비교해 대조합니다.

02 · IDENTIFY

배합목적 확인

예: 글리세린 → 보습제. 성분이 왜 들어갔는지를 찾습니다.

03 · CONNECT

설명 DB 연결

배합목적 명칭과 정의를 담은 설명 DB와 연결합니다.

04 · EXPLAIN

LLM 정보 요약

DB가 밝힌 사실을, 소비자가 이해할 문장으로 바꿉니다.
